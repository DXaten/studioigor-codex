# studioigor для Codex

Скилл для разработки **браузерных игр в OpenAI Codex** на основе [studioigor/studioigor-skill](https://github.com/studioigor/studioigor-skill) автора **studioigor**.

Оригинал предложил процесс «игровой студии»: идея, визуальные референсы, отдельные тестовые сцены для механик, игровой вертикальный срез, контент, полировка и выпуск. Здесь этот процесс переработан для Codex и сосредоточен на веб-играх. Вместо команд Claude Code используются `SKILL.md`, понятный Codex файл `AGENTS.md`, журнал состояния проекта и доступные инструменты Codex.

## Установка

Скопируйте **весь репозиторий** в каталог скиллов Codex. Для личной установки — `~/.agents/skills/studioigor-codex/`, для одного проекта — `<проект>/.agents/skills/studioigor-codex/`. Затем откройте новую задачу Codex.

```bash
git clone https://github.com/DXaten/studioigor-codex.git
mkdir -p ~/.agents/skills/studioigor-codex
cp -R studioigor-codex/. ~/.agents/skills/studioigor-codex/
```

Пример запроса: **«Используй $studioigor-codex и сделай браузерную игру про …»** или **«Продолжи эту веб-игру со скиллом $studioigor-codex»**.

## Что изменено

- Проектные инструкции Claude и `.claude/agents` заменены шаблоном `AGENTS.md`.
- Опросы и работа с инструментами опираются на возможности текущей сессии Codex.
- Вместо автономного запуска Claude по расписанию используется небольшой журнал проекта; автоматизации Codex создаются только по отдельной просьбе.
- Процесс сфокусирован на браузерных играх и ранней проверке игрового процесса.
- Сохранены и адаптированы скрипты для доски референсов и скрипт захвата кадров через Playwright.

## Требования

Python 3.9+ и git. Для захвата кадров нужны Node.js, Playwright и Chromium в проекте игры. Остальные зависимости определяются выбранным веб-стеком.
